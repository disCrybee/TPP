Проєкт продовжує предметну область лабораторної роботи №8: трейдери та біржові заявки. Збережено SQLite, sqlite_orm і Repository.

## Реалізовані патерни
- **State:** Created, Verified, Executed, Rejected. Перевіряються допустимі переходи.
- **Strategy:** максимальне нормоване значення, зважена сума, нормована зважена сума. Алгоритм можна змінити під час виконання.
- **Observer:** події реєстрації заявки та зміни її стану; незалежні підписники журналу трейдера та статистики. Підписки можна додавати й скасовувати.
- **Command:** зміна стану заявки оформлюється окремою командою та виконується через invoker.

Історія переходів зберігається в `OrderStatusHistory`. Оновлення заявки та вставлення запису історії виконуються в одній транзакції SQLite. Перед записом перевіряється очікуваний попередній статус. Сповіщення надсилаються лише після успішного завершення транзакції.

## Збірка у Windows
Потрібні Visual Studio з C++ Desktop Development, CMake та vcpkg.

```powershell
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE="C:/vcpkg/scripts/buildsystems/vcpkg.cmake"
cmake --build build --config Release
.\build\Release\TradingPatterns.exe
```

## Перевірка доменної логіки
`DomainTests` не потребує підключення до БД:

```powershell
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Тести перевіряють переходи станів, три алгоритми пріоритету, валідацію параметрів, підписку та відписку Observer, а також виконання команди.
