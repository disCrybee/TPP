# Lab 9 — SOLID Refactoring (C++17)

Лабораторна робота № 9: «Рефакторинг програмного коду. Застосування принципів SOLID під час розробки програм мовою C++».

## Зміст
- `main.cpp` — обов'язкове завдання з рефакторингу системи бібліотеки, Kata Gilded Rose, розширення Conjured та автоматичні перевірки.
- `report.md` — звіт за структурою методичних вказівок.

## Реалізація
- Інкапсуляція `Book`.
- Абстракції `IBookRepository` та `IBookNotifier`; залежності `Library` передаються через конструктор.
- Стратегії `IQualityRule` для різних типів товарів Gilded Rose.
- Індивідуальне розширення: Conjured Mana Cake (подвійне зниження якості).

## Збірка та запуск
Потрібен компілятор із підтримкою C++17 (наприклад, g++):

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o lab9
./lab9
```

Очікуваний результат перевірок: `All tests passed.` (15 перевірок assert).
