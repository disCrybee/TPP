# Лабораторна робота №5 — Варіант 15

Моделювання руху частинки в гравітаційному полі нерухомого центрального тіла (C++17, SFML 3, vcpkg, CMake).

## Запуск
1. Встановити Visual Studio з Desktop development with C++ та CMake tools.
2. Переконатись, що `VCPKG_ROOT` вказує на інсталяцію vcpkg з `scripts/buildsystems/vcpkg.cmake`.
3. У папці проєкту виконати `vcpkg x-update-baseline --add-initial-baseline`.
4. Відкрити папку у Visual Studio через File → Open → Folder.
5. Після конфігурації CMake вибрати ціль `SFML_Lab_15`, зібрати й запустити.

## Управління
- Space — запуск / пауза
- R — повторний запуск із початковими параметрами
- ↑ / ↓ — збільшення / зменшення початкової швидкості
- → / ← — збільшення / зменшення початкової відстані

У заголовку вікна відображаються початкова відстань, множник початкової швидкості, поточна швидкість, час і стан симуляції. Блакитна лінія — фактична траєкторія, темне коло — орієнтир початкової кругової орбіти.

## Фізична модель
Центральне тіло нерухоме. Прискорення частинки: **a = -μr / |r|³**, де μ = GM — гравітаційний параметр, r — радіус-вектор від центрального тіла до частинки. Використано умовні одиниці.

Початкова позиція: (cx + R, cy); початкова швидкість спрямована вгору, з модулем `sqrt(μ/R) * speedMultiplier`. Для інтегрування використано Velocity Verlet з фіксованим кроком 1/240 с. Зіткнення з центральним тілом зупиняє симуляцію.

## Експерименти
1. R=210, множник=1.00: наближено кругова орбіта.
2. R=210, множник=0.75: еліптична орбіта з нижчим перицентром, можлива зупинка при зіткненні.
3. R=210, множник=1.20: витягнута еліптична орбіта.
4. R=260, множник=1.00: кругова орбіта більшого радіуса та меншої орбітальної швидкості.
